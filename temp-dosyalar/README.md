# Planlama Dokümanları

Bu klasör, uygulama başlamadan önce hazırlanan planlama dokümanlarını içerir. Kod geliştikçe kalıcı içerik `docs/` altına (mimari, ADR, rehberler) taşınacaktır.

| Dosya | İçerik |
|---|---|
| [gelistirme-plani.md](gelistirme-plani.md) | Teknik Geliştirme Planı — ürün gereksinimleri, mimari, veri modeli, API, telemetri, değerlendirme, kabul testleri (**ne ve neden**) |
| [insa-plani.md](insa-plani.md) | İnşa Planı — faz faz iş paketleri, mühendislik standartları, repo yapısı, CI/CD, izlenebilirlik (**nasıl ve hangi sırayla**) |

İnşa Planı, Teknik Geliştirme Planı'na **GP §x.y** biçiminde atıf yapar.
